XSXB Frame Tuner Lite 便携包（Windows x64）
============================================

直接使用
--------
1. 把整个文件夹复制到笔记本任意可写位置；不要只复制其中某几个文件。
2. 双击 Start_XSXB_Lite.cmd。
3. 浏览器会打开 http://127.0.0.1:5180/。
4. 使用期间不要关闭命令窗口；完成后按 Ctrl+C 停止服务。

首次检查（可选）
----------------
双击 Verify_XSXB_Lite.cmd。它会检查脚本、自测，并验证随包携带的 Lite 项目。

已携带内容
----------
- 当前本地工作台代码（包括尚未提交的本地调整）。
- Lite 项目注册表、参数、攻击拖尾、音频/附加图绑定数据。
- Lite 稳定工作区中的原始 PNG 素材。
- Windows x64 便携 Node.js 24.14.0，无需在笔记本另外安装 Node/npm。

数据位置
--------
- 参数与清单：data\lite\
- Lite 素材：workspace\lite\
- 便携运行环境：runtime\node.exe

注意
----
- 这是 Windows x64 包。
- 请放在可写目录，否则保存参数和导出相关操作会失败。
- 如果 5180 端口被其他程序占用，请先关闭占用程序，再重新双击启动脚本。
- 所有项目路径均为包内相对路径；移动整个文件夹不会丢失绑定。
