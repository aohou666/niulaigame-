# 绿幕导帧工作台 · 橡皮擦版

根据 [sparklecatta-lang/greenscreen-frame-studio](https://github.com/sparklecatta-lang/greenscreen-frame-studio) 的 MIT 开源版本制作。本地旧改版可能在旧电脑 G 盘，本次没有找回；此目录是用户授权的新改版，保留原作者 LICENSE。

解压完整便携包到可写目录，双击 `Start_Greenscreen.cmd`，访问 http://127.0.0.1:8791/ 。无需安装 Node.js 或 npm。源码克隆后也可运行 `node server.js`。

1. 导入一组绿幕帧图片，调节抠绿阈值。
2. 切换“橡皮擦”，按住鼠标清理当前帧。支持撤销上一笔、恢复本帧擦除。笔刷直径按输出画布像素计算；移动、缩放或旋转后，擦除会跟随图片。
3. 切换“移动 / 缩放”，拖动图片或边角；右侧中心 X/Y、缩放和旋转用于调整最终导出位置。
4. 默认输出透明 PNG；也可取消透明输出，使用预览背景色。参考线和洋葱皮不会出现在导出图中。
5. “保存”保存到当前浏览器；换电脑前务必点击“导出项目”，把 `.green-project.json` 一起复制。新电脑点击“导入项目”，恢复原图、擦除笔画和位置参数。仅复制程序文件夹不会带走浏览器里的项目。

本工具输入为帧图片，不直接解码视频。导出到文件夹需要支持该功能的浏览器；不支持时会逐帧下载。
